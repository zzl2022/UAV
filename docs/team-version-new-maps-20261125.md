## 地图来源与界面

本次从目标仓库 `main` 的 `3619766` 提取地图资源、建模脚本及对应说明，保留团队版既有优化功能。整合内容如下：

- 新增无锡市市民中心：GBA LoD1 与 Overture 建筑补全、GLB、模型元数据、影像和影像落位信息。
- 更新大兴机场：完整建筑几何、GLB、元数据及影像。
- 更新杭州萧山机场：影像与实际覆盖范围信息。
- 同步影像实际范围适配和无锡全息边框适配，避免将扩大的底图反复纳入边框尺寸计算。

进入“三维环境建模 → 区域选择 → 模型”选择地图。可选河南博物院、北京故宫、深圳国际交流中心、无锡市市民中心、大兴机场、杭州萧山机场、房山核设施、海南昌江核电厂、北京—通州铁路九个场景。

切换后等待场景载入；在“部署仿真推演 → 推演输入”配置范围、采样、装备和建筑禁部署，再生成方案。Worker 按当前地图 JSON 和元数据重新建立分析场景；切图会清除旧地图报告、设备和航迹，不能沿用其他地图的优化结果。建筑连通选择读取相同的实际建筑几何。

地图中的高度及补全几何为源模型/估计结果，站点地形仍采用项目现有平面基底。数据来源、许可、建模和影像范围见 `public/gba-sites.md` 与 `docs/map-modeling-technology.md`。
