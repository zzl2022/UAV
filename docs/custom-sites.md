# 导入自定义区域

启动前端和 Python 后端。打开“三维环境建模 → 区域选择 → 增加新模型”，填写名称并选择区域数据文件夹。也可用“添加文件”补充零散文件。界面会显示文件数、大小和分类结果。检查通过后，点击“开始生成”。出现错误时，面板会保留已选文件供修改后重试。

| 文件 | 要求 |
| --- | --- |
| 建筑轮廓 | 一个 `.shp`，同目录同名 `.dbf` 和 `.prj`。可带 `.cpg` 声明编码，否则按 UTF-8 读取。 |
| 地形 | 一个带坐标系的单波段 GeoTIFF（`.tif` 或 `.tiff`）。可用文件名或子目录中的 `dem` 标记。 |
| 影像底图 | 可选一个 RGB TIFF、JPG、JPEG 或 PNG。无内嵌地理定位时，附同目录同名 JSON，填写 `crs` 与 `bbox`。 |
| 白模 | 可选一个 `tileset.json`。从 `root.transform` 读取局部坐标变换。可携带同目录的 `.glb`，页面只使用坐标变换。 |

影像定位 JSON 例如 `{"crs":"EPSG:4326","bbox":[113.64,34.78,113.66,34.80]}`。边界按该坐标系的西、南、东、北顺序填写，用实际影像范围替换示例数字。影像与 DEM 必须相交，生成的 JPEG 最长边不超过 4096 像素。未选影像时页面显示素色地面。

高度取 DBF 中的 `high`，该字段不存在时使用 `height`。字段名不区分大小写，单位为米。无有效高度或足迹顶点缺少 DEM 高程的记录会跳过，源数据哈希和跳过原因计数写入模型元数据。屋顶基面取足迹顶点中的最高高程，基础取最低高程。生成的地形网格每边最多采样 512 点，保留缺失采样值形成的空洞。无白模时以 DEM 的 WGS84 边界中心建立局部 ENU 坐标。

新模型生成后没有核心建筑。“区域选择 → 场景模型”中的“选择核心建筑”可以打开编辑面板。单击建筑可选中或取消，右侧面板显示草稿数量。输入 1–24 个字符的组名并保存后，地图以黄色高亮显示已保存的核心建筑。“修改核心建筑”可再次编辑或清除。内置模型的核心建筑由模型元数据固定，旧版自定义模型保留原来的选择，直到再次编辑。

保存通过 `PATCH /api/sites/<slug>/core` 提交组名和最多 50 个真实建筑编号。两份建筑 JSON 同步保存 `coreName`、`coreBuildings` 与兼容字段 `coreBuilding`。恰好选中一栋时，`coreBuilding` 保存这栋建筑。未选择或选中多栋时，该兼容字段为空，页面读取 `coreBuildings`。多栋核心建筑使用并集范围定位。没有核心建筑时，感知装备和任务三可使用最近的有效 DEM 采样点作为分析锚点。

自定义模型可用于建筑禁部署选择、感知覆盖方案和电磁兼容分析。威胁轨迹播放入口位于内置演示场景。

每次导入只选择一个区域。上限为单文件 64 MB、总计 200 MB、200 个文件。文件扩展名白名单为 `.shp .dbf .prj .cpg .tif .tiff .json .glb .jpg .jpeg .png`。来自目录的其他扩展名文件会被忽略。数据保存在服务器，刷新或重启后，自定义区域仍列在内置选项之后。

要删除模型，在下拉框中选中它，点击右侧的“×”并确认。界面将先切回河南博物院，再通过 `DELETE /api/sites/<slug>` 删除服务器文件和索引条目。删除成功后无法恢复。

## 命令行和存储

```text
python scripts/build_custom_site.py --input "区域数据" --slug example-site --name "示例区域" --out artifacts/custom-sites
```

命令行在输出目录内写入独立模型。平台通过 `/api/sites` 创建上传会话、逐文件暂存、轮询生成进度并读取持久化模型列表。生成成功后，后端原子更新 `index.json`，并将建筑、元数据、地形网格和可选影像一并登记。失败或取消的任务不会出现在列表里。

开发默认保存在 `public/data/custom-sites`。生产默认通过 `UAV_CUSTOM_SITES_DIR` 保存到 `/opt/uav/custom-sites`，随服务重启保留并独立于静态更新包。详见[部署说明](linux-deployment.md#自定义区域存储)。
