1. 汇报先讲的三个结论

光电近处空白主要可以由视场几何解释。 当前默认设备朝上看，近处低目标容易落在视场下缘以外；距离近、成像像素多，并不意味着目标一定在画面里。遮挡、地形缺失和采样显示还会产生其他空白，应分别判断。

六类设备的实现深度不同。 雷达、无线电和声学有简化信号预算；光电设备仿真展示几何像素和透射系数；5G-A只作几何示意，静电只作距离示意。彩色区域不能统一解释为“已检出区域”，更不能统一解释为实测概率。

默认值要按来源和计算路径解释。 资料标称、演示假设、资料缺失是三种情况。雷达默认能量预算尚未自洽重现8 km标称距离；无线电若干接收参数在参考距离反标定后抵消；光电焦距在当前设备仿真中没有直接驱动视场。这些都是组会应说明的实际模型边界。

3. 光学设备近处为什么有空白

3.1 默认设置给出的视场下缘

当前“设备仿真”的光电默认安装高度为所选表面上方30 m，俯仰为+10°；可见光分辨率为1920×1080。档案没有实际水平视场时，仿真使用60°回退假设。由图像比例推算垂直视场：

θv = 2 atan[tan(θh/2) × Ny/Nx]
θlow = pitch − θv/2
rnear = (hdevice − htarget) / tan(−θlow)

最后一式仅适用于同一水平基准、目标低于设备且视场下缘向下的情形。代入60°、1920×1080，垂直视场约35.98°，下缘约−7.99°。设备离地30 m、目标在同一平地高度时，下缘约在水平214 m处接地。因此近处低空区域可以在视场外，较远处反而进入视场。

这不是固定214 m的球形盲区。提高目标高度、降低设备安装高度或减小俯仰角都会改变近地交点。表面选在屋顶时，“上方30 m”从屋顶起算，不能一律解释为距地面30 m。模型也将地面和实体内部采样标记为不绘制，以上地面交点用于说明几何边界，不表示地表本身是有效体素。

热成像缺失水平视场时也回退为60°；640×512对应约49.58°垂直视场，同一平地例子的交点约114 m。旧部署预设的9°热视场并非此处正在使用的默认值。

4. 六类设备：原理、公式和项目实现

以下距离以m计，log为以10为底的对数。电磁频率代入传播公式时换为Hz，带宽换为Hz，线性增益与dB增益不可混用。

4.1 雷达：主动发射，接收目标回波

重点是回波功率随距离四次方衰减，目标RCS、发射能量和积累决定信号预算。基本测距原理为r=cΔt/2，但平台没有处理真实回波波形；活动模型计算：

SNRlin = Pt τ Gt Gr λ² σ N / [(4π)³ r⁴ k T0 F L]
SNRdB = 10 log(SNRlin) − ΣLscene
Rblind = c(τ + tswitch)/2
Lrain = 2(r/1000) kR rain^α
SNRreq = 10 log[ln(Pfa)/ln(Pdreq) − 1]
Pdmodel = Pfa^[1/(1 + 10^(SNRdB/10))]

Pt为峰值功率，τ为脉宽，Gt/Gr为线性收发增益，σ为目标RCS，N为积累脉冲数，T0=290 K，F/L为线性噪声系数/系统损耗。雨衰乘2表示往返路径。建筑、视场、距离、容量等另外作门控。统计Pd映射依赖模型假设，不是实测检出率。[1]

实现入口为engine.js/evaluate → physics.js/radarSnr；双径、立面和杂波采用简化代理，没有完整求解电磁散射。

4.2 无线电：被动接收无人机发射链路

重点是目标必须发射、频段匹配，接收信号要超过模型门限。本项目的参考距离标定公式为：

FSPL(r,f) = 20 log(4πrf/c)
Pr = EIRP + Gr − Lrx − FSPL(r,f)
Nnoise = −174 + NF + 10 log(BHz)
Gproc = SNRreq − (Prref − Nnoise)
SNR = Pr − Nnoise + Gproc − Lscene

代数化简后，最终裕量为：

Margin = EIRP − EIRPref + FSPL(Rref,fref) − FSPL(r,f) − Lscene

因此接收增益、NF、接收损耗和带宽在当前“每次重新反标定”的最终裕量中抵消。这是参考距离的相对比较模型，不能用它研究固定接收机带宽变化造成的真实灵敏度变化。Pfa/Pdreq会平移SNR标尺并改变统计概率映射，但在此标定机制下也不独立改变未考虑跳频捕获时的裕量边界。

跳频捕获代理为Pcapture=1−exp(−Tobs/Thop)，与统计Pd相乘。TDOA原理为|x−si|−|x−sj|=cΔtij，但平台没有解算真实站间时差，只在给定站数≥4时输出参考定位误差与GDOP的估计。实现入口为engine.js/evaluate → physics.js/radioBudget。

4.3 光电：视场内目标投影到图像

重点是先在视场内，再谈像素与成像质量。针孔近似中：

θh = 2 atan(Sw/2f)
px = Nx Wproj / [2z tan(θh/2)]
Tvis = exp[−3.912r/(1000Vkm)]
Train = 10^[−krain rain (r/1000)/20]

Sw是传感器有效宽度，f是焦距，z是相机光轴方向深度；目标投影假设与像平面平行。增大焦距会缩小视场并增加同距离目标像素。[2] 当前三条代码路径须分开汇报：

路径 实际计算 关键区别
当前设备仿真 视场、遮挡、水平像素、透射系数 使用独立仿真水平视场和斜距r近似；像素没有乘透射率，焦距不直接驱动视场，不作识别判定
部署/简化JS评估 有效像素=几何像素×照度或热对比×透射系数，再比较requiredPixels 使用size及宽/窄/热视场预设；这是一套未标定识别代理
Python资料核对 由传感器尺寸和焦距或直接视场推导视场，用光轴深度z计算水平和垂直像素 默认缺实际传感器尺寸/视场、识别像素门限，相关结果为空；显式假设后才继续推算

因此，调工作焦距而当前仿真范围不变，是这条实现路径的结果；“35 cm目标可识别”的资料陈述缺少距离和环境，不能据此推成2000 m识别保证。

4.4 声学：接收旋翼和电机声音

重点是声源级减传播损耗，再减环境噪声。当前设备仿真计算：

Lreceived = Lsource,1m − 20 log(max(1,r)) − αair r/1000
            − nbuilding Lwall − Ldiffraction − Lreflection − Lrefraction
Lnoise = 10 log[Σi 10^(Li/10)]
SNR = Lreceived − Lnoise
Margin = SNR − thresholdDb
csound = 331.3 + 0.606 T°C + windSpeed

噪声按功率叠加，不能直接相加dB。建筑遮挡增加有限损失，而不是像光电一样直接置零。反射默认关闭；开启后才计算相应反射项。风速公式是沿传播方向的一维代理，并非完整风场折射求解。

项目没有实录声波输入或真实阵列波束形成。Python资料核对另用空气、风、雨的线性距离损耗及12 dB遮挡代理；质量Q=clip[(SNR−SNRzero)/(SNRfull−SNRzero),0,1]不是检出概率。两套参数不能混算。

4.5 5G-A：通信波形兼顾环境感知

通感一体化通过通信信号及回波获得测距、测角和测速能力。[4] 单站原理可用r=cτ/2、vr=λfd/2说明，但平台没有实现时延、多普勒或阵列角度估计。

当前A9650 S49仿真只用方位、俯仰、水平/垂直张角、视线遮挡和独立仿真半径，展示距离或可达性；没有SNR、Pd或实际定位精度计算。目录的覆盖距离、业务高度和通信规格不能被理解为已经进入感知信号预算。

4.6 静电：接收目标电场变化

理想点电荷原理为E=|Q|/(4πεr²)。真实近地电场还取决于电荷分布、介质、接地和背景场；仅凭距离无法预测设备检出能力。

项目没有目标电荷、背景电场和灵敏度输入。当前CRSC-ER-1仿真只显示距离及r/R，不进行电场求解或实体遮挡追踪，不输出检出概率。厂商标称距离≥100 m、响应≤80 ms、静态功耗≤50 mW，分别不是最大量程、更新周期和工作功耗。[5]

5.2 无线电：标称距离的相对标定依赖参考波形

TDOA-X1B、mini、X1C默认4000、1250、3500 m，是资料范围2–6 km、0.5–2 km、2–5 km的中值；是参考选值，不是统计均值或保证距离。参考波形取5.8 GHz、25.5 dBm，目标取2.4 GHz、20 dBm。同距离时频率差带来约+7.66 dB，功率差−5.5 dB，净裕量约+2.16 dB；结论显著依赖该假设。

默认观测0.1 s、驻留0.01 s给出捕获代理约0.999955，几乎不构成限制；墙损15 dB/栋、20 MHz离散频点半带宽和反射幅度0.4尚无场景标定。4站、GDOP=1是有利网络条件；20/20/10 m参考定位误差不是本平台求解真实站网后的验证结果。

合理性结论：适合在共同参考条件下比较位置和信号变化；不足以作为真实接收灵敏度、跳频捕获率和定位精度证明。

5.3 光电：分辨率有资料，视场和识别门限仍缺失

1920×1080、640×512、可见光6.5–312 mm和热成像75 mm来自项目资料转录。目录中最大/最近距离、宽/窄/热视场、最低照度及识别像素门限保留空值，符合资料缺项。当前仿真回退60°，半径400 m、仰角10°、安装高度30 m是展示假设。

部署简化模型另有2000 m上限、60°/2°/9°视场、0.1 lux、8 px和雨衰0.03的假设。35 cm目标在可见光1920 px、60°视场下，忽略大气时达到8 px只约72.75 m；窄2°时理想值约2406 m，随后受2000 m裁剪和传播衰减限制。2000 m不是宽视场识别距离。

Python显式假设示例另取可见光传感器6.4×3.6 mm、12 px；热成像10.88×8.704 mm、6 px。这些值与前端8 px属于不同试算配置。合理性结论：资料值可作规格约束，展示假设可演示几何变化；识别距离需要真实视场、传感器和识别样本补齐后标定。

5.4 声学：500 m默认点处在临界预算附近

0.01–500 m、28–132 dB、最高40 dB动态范围、110 cm阵列的20 Hz–20 kHz来自项目资料转录，测试目标和声学计权条件仍须保留。94°×76°未确认为声学波束，当前设备仿真按全向处理；旧简化部署预设仍有该角度约束，不能把两条路径的覆盖画面混作同一物理结论。

当前假设声源100 dB SPL@1m；参考背景35、交通35、施工20、人群25、风噪20、雨噪20 dB，合成约38.41 dB。空气吸收3 dB/km、门限6 dB，在500 m、无遮挡且不加其他损失时，接收约44.52 dB、裕量约+0.11 dB。噪声略升即可能低于阈值。

合理性结论：这是临界场景演示，不能证明任意无人机均能探测500 m。还需目标声谱、频带/计权一致的噪声测量和检出门限标定。Python默认0.001 dB/m空气损耗、风/雨代理和−10至+10 dB的Q范围，不能与前端3 dB/km、6 dB判据混用。

5.5 5G-A与静电：资料规格与展示范围分开

5G-A目录保存1500 m以上、600 m以上、65°、128通道和通信空间流等资料转录。仿真另取1500 m半径、120°水平张角、+10°俯仰；65°仅作为初始垂直张角。业务高度600 m没有裁剪仿真高度，仿真仍默认800 m上限。合理性结论：几何展示可用，不能据此验证真实感知距离或定位精度。中兴官网方案族的现有技术说明，也不能自动替代A9650 S49型号参数。[4]

静电默认展示100 m半径；≥100 m标称距离、≤80 ms响应、≤50 mW静态功耗及−25至60℃工作温度属于规格资料。[5] 这些值没有构成当前电场预算。合理性结论：100 m只可作为距离示意，缺电荷、背景和噪声灵敏度时无法验证检出边界。
