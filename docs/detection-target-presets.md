# 无人机型号库与导入

在「三维环境建模 → 侦测目标」点击「模板」右侧的「无人机设备库导入」。内置 100 款、11 个品牌，覆盖航拍、跟拍、穿越、巡检、测绘、农业作业、物流和教育。卡片支持按品牌、型号或用途搜索，也可按品牌筛选。

点击卡片查看规格，再点击「导入到推演平台」即可载入等效可见尺寸、成像水平尺寸、成像垂直尺寸和速度。等效尺寸取长、宽中的较大值，另外两项取原规格宽度和高度。尺寸以米保存，各型号的展开与含桨口径见记录。速度采用厂商注明的飞行条件，作为可编辑的仿真初值。位置、雷达截面积、声学、热对比和无线电参数沿用当前场景。

缩略图随平台部署，可离线浏览，包含厂商公开图片和生成的同类无人机示意图。[厂商图片清单](../src/sensors/assets/drone-catalog/photo-sources.json)

## 整库 JSON

通过「导入」读取整库 JSON。界面显示读取数、新增数和库内总数。重复导入按型号编号去重，新增条目可在当前页面使用。[内置型号库 JSON](../src/sensors/drone-target-catalog.json)

文件顶层包含 `schemaVersion`（当前为 `1`）和 `models`。每条记录包括唯一的 `id`、`brand`、`name`、`type`、`dimensions`（长、宽、高，单位 m）、`speed`（m/s）、`dimensionsNote`、`speedNote` 和 `source`（HTTPS 链接）。整个文件通过校验后才会追加。

## 单个目标 JSON

「模板」下载单个目标参数示例。「导入」接受原始参数对象或包含 `target` 的对象。支持部分参数合并，保留当前目标位置。成功导入后立即应用。文件大小上限为 1 MB。
