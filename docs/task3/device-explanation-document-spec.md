# 设备部署解释明细的内容与输出规范

核对日期：2026-11-23。适用对象：方案对比中按勾选设备导出的一份合并中文 PDF。

已验收的两台设备合并示例见 [设备部署解释明细 PDF](examples/device-explanation.pdf)。示例对应文末所列运行批次，不替代用户当前方案的重新计算结果。

## 1. 文档体系核对与修订原则

本次逐份提取并查阅项目内 54 份说明与参考文件，涵盖根目录三维环境建模系列 Word、任务三成果与模型可解释性 HTML、`docs/task3/` 算法及方案比较说明、雷达与装备子模型说明、归档技术报告及任务要求 PDF；另核查已有方案对比与设备明细 PDF 成品。文件清单、源文件 SHA-256、全文提取、标题与字体统计留存在本机 `artifacts/document-review/`。

主要行文参照为 `algorithm-explanation.md`、`plans-comparison.md`、根目录《任务三模型可解释性.html》以及归档任务三多方案优化技术报告。采用“问题与约束—模型与公式—本轮参数代入—判定与取舍—验证及限制”的共同结构，保持正式技术说明与通俗解释相互对应。

现存 Word、HTML 和 PDF 的字体、字号及章节组织并非完全统一，归档表格还存在字号偏小的问题。因此本文件明确 PDF 的统一输出口径，不照搬过小字体、实验数据堆叠、仅列标称半径或未经计算的最优性表述。不得将候选覆盖预评估写成最终部署覆盖，也不得将独立覆盖写成删除设备后已完成的反事实验证。

## 2. 内容结构

1. 文档用途与数据基线：运行编号、当前方案和工况、勾选范围、采样、候选、预算、评分权重、建筑禁部署。
2. 前置条件与八步计算链：冻结输入、有效空域与候选、四工况实判、贪心及删除补选、EMC 处置、评分与盲区、威胁及移动补盲、导出验收。
3. 方案取舍：全部生成方案的指标、归一化综合分、EMC 因子；当前方案各工况覆盖、盲区归因、动态威胁和容量溢出。
4. 勾选设备逐台证据：通俗任务解释、实际坐标与安装条件、真实入选事件、预算与增益成本比、同址其他型号和姿态、附近同型号备选点、最终贡献、实际链路示例、EMC 冲突及处置、全部感知与物理参数及来源。
5. 操作与异常：界面分步操作、目标和环境参数、无数据、非法参数、零贡献、严重电磁冲突、移动搜索无解、历史证据缺失及下载失败的处理。
6. 验收与复现：勾选身份、版本批次、禁部署、成本与数量、贡献计数、电磁与盲区、现场工程确认及输入数据哈希。

“为什么不换其他设备”必须区分：本轮未配置、方案策略排除、此前已入选、剩余预算不足、本步无收益、收益成本比较低、比值并列以及证据未保存。不得把未参加比较写成性能不合格。

## 3. 真实证据与适用边界

`decision-evidence.js` 从本轮候选矩阵和 `optimizationTrace.events` 重建实际入选时刻的覆盖计数，保存同址型号/姿态的真实边际收益、相对成本、预算和候选资格。删除后补选按最新事件解释；EMC 移位关联到原设备的选择事件，并明确最终点位来自后续处置。该过程只补充证据，不改变优化选择。

`pipeline.js` 在最终位置、姿态、载频和 EMC 损耗下，逐工况保留一个覆盖及一个未覆盖采样的实判结果，优先选核心区。明细显示当前解读工况的实际信噪比/像素、门槛、裕量、距离、遮挡和失效原因。只有一种结果时只列实际存在项；未覆盖点不强行补造。移动补盲会改变组合，原固定方案的逐点示例不沿用；其最终贡献采用派生方案重新计算的结果。

`createDeviceExplanation` 输出 `task3-device-explanation/2.0`，仍按当前方案顺序展开全部勾选设备，保留原有技术说明和通俗说明字段。新增完整上下文、流程、比较证据、参数来源及验收内容。历史报告缺少候选或链路证据时明确缺失，并提示重新生成，不回填虚构数值。旧版序列化明细需要重新生成数据模型后渲染。

候选比较值来自 EMC 最终复核前的预评估；最终覆盖贡献来自处置后的设备。附近备选仅提供相同型号的局部参考，没有执行替换后的整套重优化，不能宣称选址全局最优。全部覆盖仍是离散采样结论；成本不是报价；EMC 是工程代理规则，现场施工和频谱验收须另行完成。

## 4. PDF 排版标准

- A4；左、上、右、下页边距分别为 42、50、42、44 pt。
- 嵌入项目现有 NotoSansSC 中文字体；正文 10.5 pt，主标题 22 pt，一级标题 14 pt，二级标题 11 pt，表格和注释 8.5–9 pt。
- 白底、深色正文、克制的青绿色层级强调；编号章节、页眉、页码和重复表头共同组织阅读。
- 连续排版，不为每台设备强制换页；参数表允许跨页、重复表头，表格单行保持完整。标题避免独自留在页尾。
- 不使用空白封面或为凑页数填充内容；末页自然结束，其余页面检查无异常大面积空白、文字截断、表格越界和重叠。

版式定义集中在 `src/task3/device-explanation-pdf.js`，导出仍复用 `deployment-pdf.js` 的中文字体加载和下载流程。
