# 任务三 · 使用说明（优化部署与仿真推演）

> 本模块为《创意科目二：反无装备优化部署与仿真推演》子任务三交付物，集成于既有 Vite + Three.js 项目，不改动子任务一（三维建模）与子任务二（装备建模）功能。新增代码全部位于 `src/task3/`、`scripts/task3_report.js`、`tests/task3_*.test.js`；既有文件仅 `src/main.js` 末尾追加一行入口挂载。

## 1. 启动

```bash
python -m venv .venv && .venv/Scripts/python -m pip install -r requirements.txt   # 或 .venv/bin/python（macOS/Linux）
npm ci
.venv/Scripts/python scripts/prepare_data.py   # 等价 npm run prepare:data
npm run dev
```

浏览器打开开发服务器地址（默认 5173），点击顶部 **「任务三推演 →」**。

> 数据集（创意二数据集.zip）体积大不入库：建筑 SHP/DEM/影像/白模的获取方式见任务书发放渠道；放入 `创意二文件/创意二数据集/区域数据/` 后执行 `prepare_data.py` 即可。

## 2. 网页操作流程

1. **推演输入**：勾选装备类型（装备参数.doc 七款预设，可全选或子集）、网格间距（350/500/700 m）、预算（相对成本单位，**非人民币报价**——文档未提供价格）、设备上限、四指标权重（覆盖完整性/盲区占比/成本/施工可行性，和为 1）。
2. 点击 **「开始推演」**，流水线自动串联：候选方案生成 → 覆盖推演 → 多指标择优 → 威胁场景验证 → 电磁兼容校核；各阶段状态实时显示，可随时取消。
3. **方案对比**：三套差异化候选方案（经济型·雷达+无线电 / 均衡型·全类型 / 冗余增强型·全类型+核心双覆盖）按四指标归一化加权得分排序，★ 为推荐方案；EMC 冲突方案自动降权。
4. **盲区分布**：切换覆盖工况，三维场景按四类盲区着色（楼栋夹缝/围墙边角/低空贴楼/建筑背面阴影区/其他），图例可开关类别，点击列表条目定位到盲点并查看成因（缝宽、贴楼距离、遮挡距离等）。
5. **威胁推演**：切换单机单点（8 方位）/多方向同步（4 方向）/蜂群饱和（42 架）场景，播放/暂停/拖动进度；红色为已检出目标，连线为当前帧检出设备；蜂群场景如实显示容量溢出与漏探统计。
6. **电磁兼容**：显示当前方案"通过/降额/不通过"结论与冲突清单（设备对、类型、距离、建议）。
7. **导出**：推演报告 JSON（完整方案/覆盖/盲区/威胁/EMC）与过程数据 JSON（布设规则提炼依据，schema `task3-run/1.0`）。

## 3. 命令行复算与多轮迭代

```bash
node scripts/task3_report.js           # 6 轮多配置迭代（基线/细网格/粗网格/低预算/高预算/低高度层）
node scripts/task3_report.js --quick   # 仅基线一轮，快速验证
```

输出：
- `artifacts/task3/runs/<runId>.json`：每轮完整过程数据（设置、候选统计、方案指标、四类盲区、威胁摘要、EMC 冲突），**布设规则的唯一数据来源**；
- `artifacts/task3/latest-report.json`：基线轮完整报告（含威胁逐帧）；
- 自动重新生成 `docs/task3/plans-comparison.md`、`threats-validation.md`、`emc-report.md`、`deployment-rules.md` 四份交付文档（数据全部来自当次真实仿真）。

## 6. 口径与局限（重要）

- 覆盖率为**离散采样点**口径（默认 500 m 网格 × 30/60/100 m 高度层 + 核心区近立面点），非连续空域无盲区证明。
- 成本为相对成本单位；施工可行性为重量/尺寸/架设方式/安装高度代理，屋顶承重/供电/网络未实测。
- EMC 为工程代理规则（同频/邻频/前端阻塞/共址），非频谱合规认证；选后换频（X 带 4×0.15、Ku 带 4×0.5 GHz 频道组）已自动执行，残余冲突如实列出。
- 威胁推演为运动学逐帧模型；检出全部来自子任务二感知模型对真实几何遮挡的实判，帧间漏检不排除。
- 雷达部署姿态（俯仰 0/−15/−30°、补点最低 −60°）与频道分组为模型假设，需厂家标定确认。
- 布设规则阈值适用于本场景与本采样密度；迁移他场景须用新轮次过程数据重新提炼。
