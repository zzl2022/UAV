# 建筑禁部署与已选设备解释

## 使用约定

“建筑权重”位于推演输入的权重成本内，表示建筑禁部署硬约束。单击切换选择；按住左键移动超过 5 个 CSS 像素进入追加涂选，沿路径每不超过 4 个像素采样，同次手势重复经过同一建筑不会反复切换。右键旋转、滚轮缩放；完成、Escape、失焦和模块切换会释放编辑状态。

选中连通单元通过粉红色几何覆盖层显示。选择按地图保存在内存中，刷新页面清空。更改约束立即取消旧计算并使已有方案失效，隐藏设备、停止威胁播放、禁用补盲和下载；重新手动生成方案后恢复。

## 建筑识别与计算约束

共享索引基于建筑轮廓、孔洞及立面高度，使用 128 米空间桶缩小相交判断范围，通过并查集聚合实际接触或相交的建筑实体。垂直分离实体保持独立。1 毫米容差仅处理浮点几何误差，不按名称、行政分区或批量 Mesh 判断单栋。

郑州和全部 GBA 站点使用各自的建筑 JSON。拾取先命中当前模型表面，再映射到真实建筑实体。高亮仅重建已选实体，不修改原网格与遮挡查询数据。当前郑州数据包含 15,889 个源建筑实体，几何索引识别出 11,989 个连通单元；该数值随源数据版本变化。

优化设置新增可选的 `buildingExclusions`：

```json
{"sceneKey":"recon","buildingIds":["源建筑 ID"]}
```

未传入时等同于空约束。选择连通单元后展开为其全部源建筑 ID，并存入请求快照、报告设置和运行记录。Worker 校验地图标识，未知建筑 ID 会报错。筛选先于候选抽稀，避免禁部署建筑占用高低建筑候选名额。

相同的占地判断用于初始选点、残余盲点补点、EMC 迁移、移动补盲粗搜和细搜。判定包含建筑边界并保留庭院内部；即使设备位于屋顶上方，也按水平占地约束排除。所有最终设备再次复核。无可用候选时明确失败，保留真实盲区，不降低约束；选中建筑仍参与遮挡计算。

## 解释文档

勾选按设备内部 ID 管理。重绘与工况切换保留勾选；方案、报告或地图切换清空；移动补盲更新剔除已不存在的 ID。无勾选、计算中、参数过期、建筑约束失效或导出中，按钮禁用。

`createDeviceExplanation` 接收 `report`、`run`、`activePlanId`、`conditionId`、`deviceIds`，返回版本化的 `task3-device-explanation/2.0` 数据模型。未知方案、工况、设备及空选择明确拒绝；设备按当前方案顺序去重输出，不限制为少量代表点。

每台设备包含通俗任务解释、点位与安装方式、真实入选收益和预算、同址型号/姿态取舍、附近同型备选证据、各工况最终覆盖和独立覆盖、实际链路判定示例、全部感知及物理参数、电磁冲突和处置、来源与模型限制。共用章节补充输入、算法全流程、方案比较、操作、异常和验收。零贡献、缺失资料、未验证道路与施工条件如实说明，不编造反事实收益或最优性。详细口径见 [设备解释文档规范](device-explanation-document-spec.md)。

导出开始即冻结数据，一份 PDF 对应一个方案、一组勾选和一个运行编号。使用项目已有 pdfmake 和 NotoSansSC 字体；字体加载失败会清除失败缓存，恢复网络后可重试。正文 10.5 pt，表格 8.5–9 pt；参数表使用中文名称和单位、允许跨页并重复表头。设备章节连续排版，避免强制分页和整表不可拆分造成的大面积空白。

## 验证与环境

- JavaScript：176 项通过，覆盖连通性、孔洞、边界、候选筛选、真实优化、移动补盲禁部署、全部勾选设备解释、真实候选比较、移位溯源、链路实判与数据缺失。
- Python 3.12：后端 21 项、光电 45 项、声学 36 项通过；影像 2 项通过。
- 浏览器：单选、取消、涂选、高亮、右键控制、旧结果拦截、重新优化、北京合并网格拾取、跨地图保存、清空及 390 像素窄屏通过。
- 下载：勾选和取消控制按钮；真实下载 PDF；字体首次失败后重试成功。原两台设备的 4 页摘要已扩展为含完整部署论证和操作验收的正式明细，按当前真实批次检查中文提取和逐页渲染。
- 上游装备目录：六类、九款型号、键盘操作、保存、重置、导入、导出、刷新恢复及多尺寸界面通过。
- 生产构建、三维模型导出、部署报告和感知模型报告均完成验证。构建仍有既有的大体积资源分块提示。

本机原 `.venv` 使用 Python 3.14 预览版，其 PyYAML/NumPy 原生扩展会崩溃；Python 验证改用稳定 3.12，并将依赖隔离在 `artifacts/python312-test-deps`。该本机目录不提交。正常部署使用稳定 Python 3.12 和 `requirements-integration.txt` 创建虚拟环境。

可复现实验命令及完整产物保存在 `artifacts/`。新验收入口是 `npm run test:task3:building:browser`；随后运行 `npm run test:task3:device-pdf` 验证错误重试和 PDF。它们自动关闭临时浏览器与 Vite 服务。
