# 任务三 · 标准化布设规则

> 全部规则阈值提炼自 `artifacts/task3/runs/` 的 1 轮仿真过程数据（runId：run-20261108-141804-h0h31），统计口径逐条注明；非经验拍值。适用边界：河南博物院周边 2.4×2.4 km 城区、本仓库四类装备模型与采样密度；迁移到他场景需重新标定。

## R3 声学节点优先制高点

**规则**：声学感知节点应优先部署于区域制高点：仿真中位于站点高度上 1/3 的声学候选平均覆盖采样数为下 1/3 的 1.3 倍，制高点可显著降低建筑声反射与遮挡干扰。

**数据依据**：各轮候选池声学设备按站点高度分位上/下 1/3 分组的平均 coverCount 之比，跨轮取均值（n=1 轮含声学候选）。样本量 1；来源批次：run-20261108-141804-h0h31。

## R4 无线电静默工况冗余

**规则**：无线电侦测对静默目标失效：静默工况下推荐方案采样覆盖较基线平均下降 5.3 个百分点；核心区须由雷达/光电形成不依赖目标发射的冗余覆盖。

**数据依据**：各轮推荐方案 nominal 与 silent 工况 coverageRate 之差取均值（n=1）。样本量 1；来源批次：run-20261108-141804-h0h31。

## 局限性

- 阈值为离散采样下的统计量，不构成连续空域证明；采样加密后阈值可能漂移，需用新轮次数据重新提炼。
- EMC 间距/损耗为工程代理口径，非频谱合规认证。
- 施工可行性未纳入规则（屋顶承重/供电/网络无实测数据）。
