# 对抗域适应部署策略研究与验收

## 结论

第四种方案保留为本地实验实现，未通过网页发布验收。多预算搜索在第一组留出布局上比经济型节约 13.03% 的相对成本，但单次生成约 2 秒，独立网格覆盖率预测的平均绝对误差也高于三个基准。缩减为一次生成后，成本优势消失。在新布局上重新验证，第三版与均衡型的成本、预测误差及实测仿真覆盖均持平。

## 三个角色如何交互

1. **特征提取器**接收四种工况的规划网格覆盖率、四种工况的冗余覆盖比例、四类设备数、设备总数、相对成本、预算上限和数量上限，共 16 项。输入只有整套方案的统计量。
2. **效果预测器**读取共享表示，用源域有标签样本估计名义工况下独立网格的有效样本覆盖率。部署策略据此比较不同预算产生的备选方案。训练损失采用绝对误差，以百分点解释预测偏差。
3. **域判别器**读取同一表示，预测记录来自源地图还是留出地图的无标签校准集。判别器最小化二元交叉熵。梯度反转层使特征提取器收到反向的域梯度，同时仍沿正常方向降低任务误差。这里存在两个对抗目标，效果预测器与特征提取器在主任务上协作；无证据表明该博弈获得全局最优部署。

梯度反转系数从零逐渐增加，训练上限为 0.15。判别器每步使用相同数量的源域和目标域特征。标准化只使用源域均值和标准差。第二版把任务目标改为校正原网格预测的残差，用共享编码器与四个独立抽样的回归头降低方差。其集成设计参考参数高效集成思想，另用官方 TabM 模型作独立对照。

## 跨地图预测实验

归档共 9 张地图 × 28 组配置 × 3 套基准，即 756 条。归档记录来自此前版本的规划器；当前算法的生成性能另行实测。每折用八张地图的 672 条带标签记录训练，在第九张地图按配置分组，10 组仅提供无标签特征，另外 18 组、54 条用于测试。同一配置的经济、均衡、增强方案始终同进同出。共获得 486 条图外预测。对照方法与优化方法共享测试集，目标域审计覆盖率不进入训练特征。

| 预测方法 | 跨地图平均绝对误差（百分点，越低越好） |
| --- | ---: |
| 直接使用原规划网格覆盖率 | 5.20 |
| 普通神经回归 ERM | 5.68 |
| 标准域对抗回归 | 5.98 |
| 残差域对抗回归与四头集成 | 5.76 |
| 官方 TabM 回归 | 5.34 |

残差集成仅在 9 个留图折中的 2 折优于直接使用原网格。按地图配对重采样 10,000 次，集成相对原网格的 MAE 差值为 +0.57 个百分点，描述性 95% 区间为 −0.17 至 +1.20 个百分点。域对齐没有带来稳定收益。原网格结果已经提供较强的物理模型先验，小样本校正可能把真实的环境差异与无关偏差一并消除；这是有待验证的解释。

## 三次迭代的完整生成测试

归档耗时包含三套基准的共享计算，无法拆成可靠的单方案计时。为此建立独立的合成建筑几何测试：三组布局用于开发，每组测试使用四个未参与训练的布局，每布局每方法轮换顺序测量三次。基础规划器、装备目录、采样输入和几何查询相同。各方法在已加载的场景中独立生成，计入选项搜索、合法性检查和模型推断。以每个布局三次计时的中位数求四图平均。独立审计网格在选定方案以后才计算，所有方法均排除模型冷加载、浏览器渲染与审计计时。帧明细导出统一关闭。三个基准的预测值统一采用本身的名义规划覆盖率。

**第一版**在三个预算系数 0.45、0.65、0.90 下调用现有均衡型生成器。根据已学习的独立网格覆盖率预测，在预测接近最好值 1 个百分点以内的可行选项中选择成本最低者。系数乘在进入均衡求解器之前，均衡求解器仍使用原有 0.75 预算比例。**第二版**在三个开发布局上将预算档固定下来，把每次求解次数从三次降为一次。

| 首轮留出结果 | 相对成本 | 生成时间（秒） | 覆盖率预测 MAE（百分点） | 审计覆盖率 |
| --- | ---: | ---: | ---: | ---: |
| 经济型 | 34.94 | 0.602 | 1.62 | 95.29% |
| 均衡型 | 35.94 | 0.671 | 1.37 | 95.47% |
| 增强型 | 45.41 | 0.763 | 1.37 | 95.47% |
| 第一版·多档搜索 | 30.39 | 2.000 | 2.25 | 95.30% |
| 第二版·单档生成 | 35.94 | 0.659 | 2.13 | 95.47% |

第一版在四组中各两次选到低档和高档，确实按输入改变了预算；三次完整求解抵消了推断开销较小的优势。第二版选用了高档，成本与均衡型相同。两版各 12 次均通过预算、设备数量、几何和严重兼容性检查。

**第三版**限制模型校正幅度。在独立的三组开发布局上，用标签选择残差混合权重及预算档，然后锁定配置，换用四组新布局确认。开发集选择的校正权重为零，表示这批数据支持保留原网格预测。新布局上第三版成本 35.99、预测 MAE 2.59 个百分点、覆盖率 93.41%，与均衡型相同；经济型成本 33.26，增强型覆盖率 93.92%。各基准及实验方法均完成 12 次可行生成。逐次耗时和全部测量保存在验收记录中。

## 发布判定和适用边界

每种实验策略分别与三种基准作配对比较。成本、生成耗时、覆盖率预测误差均应严格下降；同时检查候选合规及审计覆盖不下降，防止依靠移除服务范围节约成本。当前没有策略同时通过，网页继续提供原有三个选项。局部最优、单一地图优势、计时波动以及与基准持平均不计作超越。

独立审计网格沿用同一仿真感知模型，只测规划网格对另一组空间采样的泛化。真实检出率、定位误差、虚警率及上报时延需要带时间戳的独立观测与参考真值。相对成本也不能直接解释为采购价格。本轮数据支持一项明确判断：现阶段不能以域对抗学习为由宣称部署效果全面优于现有系统。

## 本地复现

在仓库根目录执行。需要本项目 Node 依赖、Python、CPU 可用的 PyTorch 和 NumPy。原始归档为 `artifacts/cross-map-study/all-plan-results.jsonl`，SHA-256 为 `bad10a0fe7bf9d8011a59b71efb3a13d1c0bc8b8ed2dd7f695d635bf60df7d8b`。训练随机种子 734，单线程 CPU，240 步；TabM 对照采用 4 成员、两层、宽度 32。未开展跨训练种子的置信度评估。整机并发负载和硬件会影响绝对耗时。

```powershell
git clone https://github.com/thuml/Transfer-Learning-Library.git artifacts/domain-study/upstream-tllib
git -C artifacts/domain-study/upstream-tllib checkout c4aa59eb565650a552b809411601d0589efbbfe4
python -m pip download --no-deps --only-binary=:all: --dest artifacts/domain-study/wheels tabm==0.0.3 rtdl-num-embeddings==0.0.12
node scripts/domain-study/fixtures.mjs
python scripts/domain-study/upstream_check.py
python scripts/domain-study/study.py
python scripts/domain-study/tabm_reference.py
node scripts/domain-study/benchmark.mjs
node scripts/domain-study/benchmark.mjs --confirm
```

`study.py` 保存留图误差、开发布局选择结果和可供 JavaScript 加载的权重；`benchmark.mjs` 实际调用生成器，返回所选方案，在方案确定后复核独立网格，并保存逐次测量。两种语言推断输出已逐项对齐。冻结的测量快照随本说明交付。
