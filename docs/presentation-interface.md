# 展示界面的结果说明

> 当前展示已改为 [装备建模统一入口](equipment-unification.md)。中文页面及HTML报告只展示有可用结果的指标，不再显示空值占位或开发说明。完整状态仍保留在JSON，原独立面板不再挂载。以下为此前展示调整的历史记录。

公开页面和中文报告使用面向使用者的中文结果。距离、视场、遮挡、参数来源及未知状态继续显示；实现细节保留在技术文档与完整 JSON 中。

结果下方的“评估条件与数据状态”默认折叠，说明仿真点位、高程基准待核验、缺失的视场参数及声学标称距离的适用条件。折叠只改变展示方式，不改变计算、校验和来源标记。

截图中原有的开发说明对应以下技术事实：

- 建筑读取 `high` 并解释为相对米高度，结合 DEM 网格计算；字段含义与垂直基准仍需核实。
- 设备及目标位置由用户设置，不属于实测部署点。
- 光电适配实际复用 `field_of_view`、`camera_components`、`Pose`、`Target`。
- 云台机械转动范围不能代替相机瞬时视场，缺少视场参数时结果仍为空。
- 资料中的 50 m、切向 15 m/s 为跟踪条件，不能用作最大识别距离。
- 声学调用 `AcousticSensor.evaluate`；当前资料模式未提供环境和测角标定数据。
- 声学存在建筑遮挡时，不能仅凭直线相交判断探测能力必然为零。

以上原始说明仍在后端 `notes` 及导出 JSON 中保留。中文报告正文使用通俗的适用条件，报告末尾“完整计算与输入”保留完整技术记录，便于核查。

该修改仅涉及界面和报告措辞，设备参数和模型数值计算不变。
