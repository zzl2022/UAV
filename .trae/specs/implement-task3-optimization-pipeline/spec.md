# 任务三：反无装备优化部署与仿真推演 Spec

## Why

任务书子任务三要求"以最优装备配置体系实现核心防护区域全域无盲区感知覆盖，完成多套布设方案的自动化仿真推演与迭代优化"。仓库现有 `src/planning` 雏形（经济/均衡/增强三方案贪心集合覆盖、四工况、雷达同频 EMC 代理、单航线飞行报警）缺少：四类盲区分类排查、三类威胁场景推演、按装备频段参数的完整 EMC 校核、布设规则提炼、SOTA 模型选型对比报告与自动化串联，不满足任务书六项要求与初赛评分标准（部署方案优化 30% + 布设规则 15% + 电磁兼容 10%，另含电磁传播加分项 ≤10 分）。

## What Changes

- 新增独立目录 `src/task3/` 承载全部任务三代码；**不删除、不重命名、不改动任何现有文件**（仅在 `src/main.js` 末尾追加任务三入口挂载的导入行，不动既有逻辑）
- 四类盲区分类排查与可视化：楼栋夹缝、围墙边角、低空贴楼区域、建筑背面阴影区
- 四指标综合评估与 ≥3 套候选方案自动择优：覆盖完整性、盲区面积占比、装备配置成本（相对成本单位，显著标注"非人民币报价"）、现场施工可行性（以装备参数.doc 的重量/尺寸/架设方式/安装高度为代理）
- 三类威胁场景鲁棒性验证：单机单点入侵、多方向同步入侵、蜂群饱和攻击
- 按装备参数.doc 频段参数（雷达 X≈9.4GHz / Ku≈15GHz；无线电 100MHz–6GHz 与 0.9/1.2/2.4/5.2/5.8GHz）的电磁兼容校核与报告
- 标准化布设规则提炼：阈值全部来自多轮仿真过程数据，过程数据持久化存档于 `artifacts/task3/`
- 自动化流水线串联：候选方案生成 → 覆盖推演 → 多指标择优 → 威胁场景验证 → 电磁兼容校核
- `docs/task3/` 交付文档：模型选型对比报告、多方案评估对比数据、鲁棒性验证结果、EMC 校核报告、布设规则文档（含仿真数据支撑）、使用说明
- 完成后在新分支提交，向 `https://github.com/zzl2022/UAV.git` 提 PR；数据集等大体积文件不入库，仅在文档说明获取方式

## 已确认口径（用户决策）

- 核心防护目标：**河南博物院**（数据说明原文与代码 DBF.NAME 匹配为准；非"郑州市博物馆"）
- 推演评估范围：**博物院周边 2.4×2.4 km**（现有代码 core scope，±1200 m）；数据集不存在"半径 10 公里"范围，任务书亦未给定半径
- 成本指标：沿用**相对成本单位**（雷达 12 / 无线电 5 / 光电 4 / 声学 2），界面与报告显著标注"非人民币报价"；装备参数.doc 无价格数据
- 流程：先出阶段计划 + SOTA 模型选型对比报告，用户确认后再集成实现

## Impact

- Affected specs：子任务三部署优化（新增能力）；子任务一（三维建模）、子任务二（装备建模）仅做回归保护
- Affected code：新增 `src/task3/*`、`scripts/task3_*.js`、`tests/task3_*.test.js`、`docs/task3/*`；`src/main.js` 仅追加入口行；只读复用 `src/sensors/*`（engine/presets/physics）、`src/planning/optimizer.js`（采样/候选/贪心/EMC 代理）、`src/landmarks.js`

## ADDED Requirements

### Requirement: 模型选型对比报告（阶段零，先于集成）

针对需求理解、白模/地形解析、候选方案生成与部署优化、覆盖/盲区仿真、威胁场景推演、电磁兼容校核各环节，系统 SHALL 输出开源 SOTA 模型/算法对比报告：每环节 ≥3 个候选，说明各自优劣、开源协议、部署成本，并推荐一个可拼接的组合方案，注明运行方式（前端 WASM/ONNX 或后端 API），且与现有 Vite 前端 + Python 架构兼容。报告经用户确认后方可进入集成实现。

#### Scenario: 报告确认

- **WHEN** 阶段零产出 `docs/task3/model-selection.md`
- **THEN** 用户确认推荐组合后，后续阶段按该组合集成；若候选均不适用，报告须明确说明并采用自研方案及理由

### Requirement: 四类盲区分类排查

系统 SHALL 对每套候选方案的覆盖盲点逐一分类：楼栋夹缝、围墙边角、低空贴楼区域、建筑背面阴影区（无法归入者标"其他"并说明），并在三维场景中按类别着色、可筛选显示；每个盲点记录几何成因数据（夹缝宽度、贴楼距离、遮蔽建筑编号等）。

#### Scenario: 盲区分类可视化

- **WHEN** 用户在任务三面板选择某方案并查看盲区分布
- **THEN** 地图按四类盲区分别着色显示盲点，点击盲点可见类别与成因数据，可切换类别筛选

### Requirement: 多方案四指标综合择优

系统 SHALL 自动生成 ≥3 套候选部署方案（点位、类型组合、安装高度、覆盖角度各异），按覆盖完整性、盲区面积占比、相对成本、施工可行性代理四指标归一化加权评估，自动推荐最优方案并展示对比表；权重可调。

#### Scenario: 自动择优

- **WHEN** 候选方案生成与覆盖推演完成
- **THEN** 界面呈现 ≥3 套方案的四指标对比表与推荐结果，推荐依据可展开查看

### Requirement: 三类威胁场景鲁棒性验证

系统 SHALL 对最优方案执行三类威胁推演：① 单机单点入侵（多条不同方位航路）；② 多方向同步入侵（≥4 方向同时进入）；③ 蜂群饱和攻击（目标数超过装备并发容量）。输出首报时间、持续检出率、漏报帧数、容量溢出与漏探统计。

#### Scenario: 蜂群饱和验证

- **WHEN** 蜂群目标数超过方案装备的并发容量（如雷达 500 批、TDOA-X1B 35 架次）
- **THEN** 报告如实给出容量溢出数量与漏探架次，不伪造全检出结论

### Requirement: 电磁兼容校核

系统 SHALL 按装备参数.doc 的频段参数校核方案内全部设备对的同频/邻频干扰与信号互扰，输出冲突清单（设备对、频率差、间距、附加损耗）与 EMC 校核报告，给出"通过/降额/不通过"结论。

#### Scenario: 同频干扰识别

- **WHEN** 两台发射/接收频段重叠且间距不足的设备同时出现在方案中
- **THEN** EMC 报告列出该冲突对、量化附加损耗并给出规避建议（换频、拉距、换型）

### Requirement: 标准化布设规则提炼

系统 SHALL 基于多轮仿真过程数据提炼 ≥5 条通用布设规则，形式如"两栋建筑间距小于 X 米且高度差大于 Y 米时，应在较低建筑顶部增设补盲节点"；规则中的全部阈值（X/Y/Z/W 等）来自 `artifacts/task3/` 仿真数据统计，文档注明数据来源与适用范围。

#### Scenario: 规则阈值可追溯

- **WHEN** 审阅布设规则文档
- **THEN** 每条规则的阈值均可追溯到具体仿真批次与统计口径，无拍脑袋填写的数值

### Requirement: 自动化流水线与网页呈现

系统 SHALL 在网页一键串联：候选方案生成 → 覆盖推演 → 多指标择优 → 威胁场景验证 → 电磁兼容校核；用户可选择/导入地图白模、勾选装备类型、设置预算与网格后获得优化部署方案；可视化内容包括部署点位与类型、各方案覆盖范围对比、四类盲区分布、威胁场景推演过程。

#### Scenario: 一键推演

- **WHEN** 用户在任务三面板点击"开始推演"（默认参数）
- **THEN** 系统依次完成五个环节并展示进度，最终呈现推荐方案与各环节结论，无需手工逐步执行

### Requirement: 子任务一、二回归保护

每阶段结束 SHALL 运行既有验证（`npm test`、`npm run report:sensors`、`npm run plan:build` 等），确认三维建模、装备建模与既有部署/飞行功能不受影响。

#### Scenario: 阶段回归

- **WHEN** 任一实施阶段完成
- **THEN** 既有测试全部通过，子任务一/二页面功能行为与基线一致

## REMOVED Requirements

无。不删除任何既有功能。
