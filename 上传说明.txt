上传步骤：
1. 解压ZIP，先打开“上传到仓库”文件夹。
2. 将其中的src、backend、equipment_models、docs、package.json等内容放到现有仓库根目录。
   不要把“上传到仓库”这层目录上传为子文件夹，也不要仅上传ZIP而期待页面自动更新。
3. 推荐在现有仓库新建分支，例如integrate-equipment-20261029，将文件复制到克隆目录后提交、推送。
   GitHub网页上传时，在仓库根目录选择Add file → Upload files，保持原目录结构；单次不超过100个文件，按目录分批上传。
   .github是带点目录，使用Git客户端复制、提交时一并包含。
4. 本包包含平台代码快照。若团队在基础提交之后改过同名文件，请合并双方修改，保留队友的新代码。
5. 保留仓库原有“创意二文件”比赛数据目录；本包没有重复打包大体积建筑、DEM、影像和白模。
   不要删除仓库原有但本包未包含的文件。本包不用于从空仓库直接运行。

已排除node_modules、.venv、.git、缓存、dist和public/data等生成数据。

Windows首次安装与运行（仓库根目录）：
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-integration.txt
npm ci
.venv\Scripts\python.exe scripts/prepare_data.py
.venv\Scripts\python.exe scripts/start_integrated.py

之后可双击“启动装备建模平台.cmd”。浏览器打开http://127.0.0.1:5173/，点击“装备建模”。
macOS/Linux将.venv\Scripts\python.exe替换为.venv/bin/python。
只上传文件不会自动更新正在运行的服务；需更新依赖、重新构建或重启实际运行的平台，再刷新浏览器。
页面和Python服务都要运行。静态站点部署还需在服务器运行Python，并将/api/capabilities代理到模型服务。
仅GitHub Pages或dist静态文件不能单独执行Python光电／声学评估。

验证命令：
npm test
.venv\Scripts\python.exe -m pytest backend/test_capabilities.py -q
.venv\Scripts\python.exe -m pytest equipment_models/optical/tests -q
.venv\Scripts\python.exe -m pytest equipment_models/acoustic/tests -q
npm run build
以上三组Python测试分别执行，避免两套模型中的同名测试文件发生导入冲突。
