## 1. 建模对象与装备参数

建模对象为题设两型三坐标雷达：**02C**（X 波段线性调频脉冲，方位机扫+俯仰相扫）与 **03D**（Ku 波段 DBF，方位机扫+俯仰相扫）。参数分任务书给定值与工程反推假设值两栏，假设值均由"8 km@RCS=0.01 m²"指标反推并校核通过：

| 参数 | 02C | 03D | 来源 |
|---|---|---|---|
| 中心频率 | 9.4 GHz | 15 GHz | [假设] 波段典型值 |
| 探测距离（指标） | ≥8 km | ≥8 km | 任务书 |
| 俯仰覆盖 | 0–40° | 0–60° | 任务书 |
| 距离/方位/俯仰精度 | 8 m / 0.6° / 0.4° | 6 m / 0.3° / 0.3° | 任务书 |
| 数据率 / 目标容量 | 3 s / 500 批 | 2 s / 500 批 | 任务书 |
| 带宽（由距离精度换算） | 18.75 MHz | 25 MHz | 推算 |
| 脉宽 / PRF / 相参脉冲数 | 2 μs / 12 kHz / 128 | 2 μs / 10 kHz / 40 | [假设] |
| 峰值功率 / 收发增益 | 1 kW / 35 dB | 2.2 kW / 38 dB | [假设] 反推校核 |
| 噪声系数 / 系统损耗 | 3 dB / 4 dB | 4 dB / 4 dB | [假设] |

模型通过 `config/radar_02C.m`、`config/radar_03D.m` 配置化，**输入任意厂商/型号参数即可动态重构模型**，满足赛题"参数动态可调"要求。

## 2. 模型体系

### 2.1 自由空间探测性能（能量形式距离方程 + Swerling I 检测）

相参积累后 SNR 按能量形式距离方程计算；检测模型取 Swerling I（小无人机RCS脉间起伏的典型模型），所需 SNR 由 `Pd = Pfa^(1/(1+SNR))` 闭式反解。取 Pd=0.9、Pfa=10⁻⁶ → 需相干 SNR 21.14 dB。

**验证结果（RCS=0.01 m²，Pfa=10⁻⁶）**：

| 指标 | 02C | 03D | 判据 |
|---|---|---|---|
| 最大探测距离 | 8.42 km | 8.09 km | ≥8 km ✅ |
| 不模糊距离 | 12.5 km | 15.0 km | ≥R_max ✅ |
| 驻留内可用脉冲数 | 164 | 45 | ≥相参需求 ✅ |

### 2.2 五类城区环境损耗机制

| 机制 | 模型 | 量化结论（RCS=0.01，架高10 m） |
|---|---|---|
| 气象衰减 | 雨衰按 Marshall-Palmer 谱积分，云雾按液态水含量 | 暴雨50 mm/h：02C 8.35→4.19 km，03D 7.96→2.65 km（Ku 波段雨衰显著更重） |
| 电磁底噪 | ITU-R P.372 人为噪声分级；附加 EMI 以 dB 抬升注入 | 城区人为噪声低于系统噪声，底噪抬升≈0 dB；EMI+6 dB 时 02C 降至 5.93 km |
| 地面多径 | 平坦地面双径干涉，水平极化菲涅尔反射系数 + 瑞利粗糙度因子（εr=6、σ=0.02 S/m、h_rms=0.1 m [假设]） | 低空存在周期性零陷：首陷 02C@3.1 km、03D@3.6 km；架高 3→25 m 几何盲区 1.08→0.57 km |
| 建筑遮挡+衍射 | 视线水平投影 → 50 m 栅格索引 → 多边形精确求交判遮挡；遮挡后按首个遮挡建筑顶为刃峰计 ITU-R P.526 单刃峰衍射损耗 | 楼顶架设（AOI中心，128 m）平均遮蔽角 4.6°；衍射示例：河南博物院遮挡，刃峰高差 29.4 m → 损耗 35.2 dB（02C）/ 37.2 dB（03D），SNR 由 38.8 降至 3.7/0.9 dB，低于检测门限 → **遮挡区基本不可探测，衍射只能挽救擦顶目标** |
| 近距盲区 | 单基地脉冲 R_min = c(τ+t_sw)/2，τ=2 μs，收发切换 t_sw=1 μs [假设] | **R_min = 450 m**，两型一致 |

### 2.3 失效边界（B5 综合指标）

定义三个口径：最大连续探测距离（自近距盲区边界起连续 Pd≥0.9）、首次零陷距离、盲区比例（0~R_max_free 内 Pd<0.9 占比）。

- 无雨无 EMI、RCS=0.01、高 50 m：02C 连续探测 2.83 km / 盲区比例 21.3%；03D 3.56 km / 16.4%（03D 俯仰 60° 覆盖使其低空连续段更长，但中雨场景衰减更重）
- 低空小目标（20 m、RCS=0.005）连续探测距离收缩至 1.77–2.49 km，主要由多径零陷与几何盲区截断

**全因子 Pd 概率图**（`results/composite_pd_map.png`）：自由空间+气象+底噪+地面多径+建筑遮挡/衍射+近距盲区统一输出 R-H 二维 Pd。楼顶单站架设、100 m 高度层、8 km 内：中位方位覆盖 15.6%，最差方位 3.1%——直观呈现密集城区单雷达的低空覆盖瓶颈，为部署补盲提供量化依据。

### 2.4 虚假目标生成机制（现象级）

`environment/ghost_target_model.m` 覆盖三类城区典型虚警源：

| 机制 | 模型 | 量化示例 |
|---|---|---|
| 多径鬼影 | 反射路径超前量 ΔR=2h_r·h_t/R，鬼影位于 R+ΔR；超前量 >2 倍距离分辨单元（02C 8 m / 03D 6 m）时成为独立假目标 | 目标 2 km/50 m：ΔR=1.5 m < 分辨单元 → 不可分辨，表现为 SNR 干涉起伏（即 §2.2 多径零陷的另一种表述）；仅在极近距/极低空时解出独立鬼影 |
| 建筑角反伪峰 | 墙角二面角/三面角强散射体，城区等效 RCS 10–100 m² [假设]，按 Swerling I 算超门限概率 | RCS=30 m² @3 km：SNR≈74 dB，**每扫描圈必报假目标** → 高楼角部必须在部署与航迹关联中剔除 |
| 热噪声批虚警 | 单圈 n 个 RD 单元至少一次虚警概率 1−(1−Pfa)ⁿ | 02C：128,000 单元/圈 → 0.12；03D：53,320 单元/圈 → 0.05 |

## 3. 复现方式

```
matlab -batch "cd('<项目根>'); run_all"
```

六个仿真顺序执行（自由空间 → 气象底噪 → 多径 → 遮挡衍射 → 失效边界 → 全因子Pd+虚假目标），输出全部图件于 `results/`。LOS 查询性能 0.8–1.1 ms/次，全流程约 2 分钟。

## 4. 与任务一的对接（数据替换接口）

模型引擎与场景解耦，仅通过以下两个缓存文件对接：

| 文件 | 字段 | 说明 |
|---|---|---|
| `data/buildings_enu.mat` | `buildings.enu_x/enu_y/height/name` | 建筑轮廓局部 ENU 坐标 + 高度（m） |
| `data/dem_enu.mat` | `dem_data.x/.y/.Z` | DEM 规则 ENU 网格（m，正常高） |

坐标约定：ENU 原点 AOI 中心（113.662169°E, 34.788899°N），与 `tileset.json` 的 ENU→ECEF 原点一致；高程为 1985 国家高程基准正常高。任务一正式数据按上述字段生成后调用 `data/preprocess_city.m` 重建缓存即可全量重跑。

对下游（部署推演）暴露三个查询：`city_los`（通视+衍射损耗，含 freq_hz 参数）、`city_mask_map`（360° 遮蔽角）、`composite_snr_db`（全因子 SNR）。

## 5. 局限性

1. **遮挡判定按建筑整体外轮廓+统一高度**，未建模女儿墙、塔楼错落与楼面细节；白模高度字段不可用，关键建筑高度需实测校准
2. **多径仅含地面双径**，建筑立面反射未单独建模（其效应部分并入地面多径因子与角反伪峰）
3. **地形遮挡未建模**（城区 30 m DEM 起伏 65–137 m，影响限于远距低仰角）；DEM 30 m 格网存在建成区斑块噪声
4. **假设参数**（功率、增益、噪声系数、收发切换时间、地面电磁参数、角反 RCS）为工程典型值，灵敏度留待答辩质询时按需补充
5. 衍射取单刃峰近似且刃峰位置用建筑质心，对宽建筑的横向绕射略有高估（保守方向）
