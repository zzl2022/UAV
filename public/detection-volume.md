# 三维探测场与连续物理量渲染

2026-10-23 更新。已将旧的平面格子/三层切片改为真正的三维标量场，旧切片说明不再适用。

## 计算与显示

每个 X/Y/Z 体素独立调用已有雷达或无线电模型，计算真实三维斜距、方位与俯仰、近距盲区、建筑/地形遮挡、雨雾与干扰损耗、地面双径及可选的一次立面反射。雷达沿用能量方程与相参积累，无线电沿用单向链路、接收机热噪声与反推处理增益。体数据包含 Float32 裕量、SNR、统计 Pd 和独立有效性掩码。

显示使用 WebGL2 的三维纹理与 GPU 光线步进，连续插值物理值，再通过 256 级色带着色，不再把所有结果压成三种颜色。提供两种观察方式：

- **连续体渲染**：沿视线累积透明度，可以看到空间厚度与内部衰减，体密度滑块调节透明程度。
- **门限等值面**：沿视线寻找第一个满足显示下限的有效边界，七轮二分细化交点并按梯度着色；更适合看近距盲区、俯仰边界和阴影轮廓。受范围裁切、数据缺口或硬掩码限制时，边界也会在这些位置截断，并不都代表信号门限边界。

城市深度预通道用于截断体光线，避免体场穿透建筑/地面。切换物理量、色带、显示门限、体密度、剖切位置不需要重新进行传播计算。

## 物理量含义

| 量 | 含义 | 默认色带 |
| --- | --- | --- |
| 探测裕量 | 实际 SNR 减相应检出门限，0 dB 是模型信号门限 | 根据当前场的数值范围自动缩放，并包含 0 |
| 处理后 SNR | 雷达相参积累或无线电处理增益之后的 SNR | 根据场值自动缩放 |
| 统计模型 Pd | 使用各设备 Pfa 和对应 SNR 的假设统计响应，无线电包含跳频捕获因子 | 固定 0–1 |

自动色带始终显示真实数值刻度。取消自动缩放时，裕量使用 −20–40 dB，SNR 使用 −10–60 dB。超出色带端点的数值仅在显示时饱和，导出保留原值。

低于 SNR 门限的信号仍有连续的信号响应，而不是全部归零。默认裕量显示下限为 0 dB；降低显示下限可观察弱信号场。脉冲盲区、超出标称距离、视场外、雷达实体阻断、无线电静默/频段不符等硬失效不被恢复为有效体素。

多装备图层对每个物理量分别取满足几何条件的最佳单设备值，保存对应设备索引，不将相关设备的概率相加。SNR 最大的设备与裕量/Pd 最大的设备可能不同。旧方案没有物理统计参数时，Pd 不被虚构生成。

## 空间精度与边界

可选水平/垂直步长为 150/75 m、100/40 m、50/20 m。默认标准档为 100/40 m，可在“空间精度”选择精细档。每个轴都有独立采样位置，绝不是只计算三个高度。体数据限制为最多 180000 个采样点；高空或全域分析超限时自动调整步长，图例显示实际 X/Y/Z 步长和维数。

分析高度可选离地 300/600/1200/3000/8000 m；采样纹理为规则 ENU 三维网格，但按每个位置的 DEM 限制离地上限。当前装备周边 3×3 km 或整个建模城区只是分析范围，不等于设备标称最大范围；可勾选“叠加标称范围体”对照未受环境限制的标称体。

独立掩码区分未知、可计算信号、硬失效、实体、超出分析高度。采用最近体素的硬掩码，连续插值只使用有效信号邻居，避免把建筑阴影或近距盲区插值成有效覆盖。代价是硬边界仍受真实采样间距限制，精细档能减轻阶梯，不会凭插值获得新的物理精度。

没有 DEM 的区域不外推地面或虚构无遮挡。统计 Pd 非实测检出率，精细网格也不代表模型已实测标定。米级步长仍无法解析厘米波双径的全部快速相位起伏，不应据此宣称精确电磁全波仿真。

## 交互、性能与验证

后台 Worker 建立独立 BVH/地形索引并分批计算，主线程负责交互和 GPU 渲染。参数变化清空旧结果、取消旧任务；导出只针对当前已完成的场。修改渲染量或剖切不会启动旧任务重算。

鼠标悬停体场显示该空间位置的连续插值，并用现有引擎在实际空间坐标复核链路预算；二者可能存在采样插值误差。导出 JSON 包含三维维数、原点、实际步长、四个通道的浮点数组、每个指标的设备索引、有效性掩码、输入方案与坐标变换。

验证：`npm test`、`npm run build`、`npm run test:detection:browser`。体数据测试对照不同高度的引擎结果，验证三线性插值、硬边界、连续色阶、静默、弱信号 Pd、实体与高度限制；浏览器测试验证 GPU 着色器、等值面、剖切、体内查询、联合场、取消旧任务、导出与移动布局。
