# 赛题核对与模型接入进展（2026-10-22）

依据：`创意二文件/07--创意科目二：反无装备优化部署与仿真推演（公开发布版）(1).pdf`、装备参数文档及现有代码。此次工作的“建模”指装备感知能力与传播模型，不是装备外观网格。

## 原有进展

- 子任务一：真实建筑轮廓、高度、DEM、影像、原始白模对比、ENU 配准与导出均已实现，15889 栋建筑；为 LoD1，不包含未提供的围墙、树木、建筑材质细节。
- 子任务二：已有雷达、光电、无线电、声学七种型号的参数化近似与地图交互；独立 `radar/`、`rf/` MATLAB 成果尚未用于网页链路预算。
- 子任务三：已有预算约束部署、四工况采样覆盖、EMC 代理、飞行与报警回放。原示例的数据哈希与本机重新生成的数据不一致，需要重算。

## 本次完成

- 新建雷达默认使用 `radar/core/radar_snr.m` 的能量形式雷达方程，沿用 02C/03D 收发配置、相参积累、Swerling I 统计公式和脉宽/切换时间盲区（约 450 m）。频率修正为 9.4/15 GHz。自由空间最大距离约 8.42/8.09 km，与 MATLAB 报告一致。
- 新建无线电默认使用 `rf/` 的 FSPL、接收功率、热噪声、城市中值半径灵敏度反推与处理增益。增加跳频捕获窗口、NLOS 时差偏差。静默/频段不匹配时不输出有效接收功率或检出概率。
- 物理参数可在“装备建模 → 雷达 / 无线电物理链路参数”修改，并随参数方案导入导出。旧方案无 `physics` 字段时保持旧参考预算方式。
- 装备视图使用有限立面镜像法寻找一次反射，校验墙面边界、高度及两段路径遮挡；以黄色虚线显示路径。雷达/无线电加入相干反射增强或衰落，声学增加回声超额时延及单程距离偏差。
- 光电识别距离改为求解随距离变化的消光与像素门限，低照度/实体遮挡时为零；宽窄视场和热成像仍分别处理。
- 更新默认部署示例与真实城市多工况感知报告；检出概率明确为假设统计模型值，与原有裕量评分区分。

## 模型边界与仍需完成的赛题工作

这次移植的是 MATLAB 核心预算，并非完整 MATLAB 环境模块逐项复现。地图继续使用真实三角网格/DEM 遮挡、既有双径、可调雨衰和干扰模型；未将旧 MATLAB AOI 坐标或 GeoTIFF 直接冒充地图局部坐标。

立面搜索限定在路径中点周围 3×3 个 150 m 网格，最多检查 24 面墙并保留 3 条路径；不是完整楼群多次反射解。部署批量计算默认关闭立面反射搜索以控制成本，所以装备精查与规划代理可能有差异。没有反射路径不等于环境不存在反射。

无线电保留文档离散频点加容差，未把 `rf/config/rf_x1c.m` 中扩展频段假设当作厂家实测。NLOS 偏差采用 `multipath_tdoa_bias.m` 商业区 2% 距离假设；定位误差仍是站数/GDOP 代理，未完成真实站网时差定位解算。未移植 MATLAB 全部波形库与环境噪声分类。

光电识别准确率需要标注图像与算法验证，声学需要实测声谱、材质与折射剖面，雷达需要厂家曲线和实测标定。当前没有这些输入，不能把工程近似写成已验证真实性能。

赛题的多方向/蜂群同步入侵、施工可行性数据、通用部署规则自动提炼和跨场景迁移仍需后续完整实现与验证。本次没有将这些项目标记为完成，也没有将采样覆盖率等同连续空间全覆盖。

## 使用与复现

当前 Windows 环境可用 `npm.cmd run dev` 启动。打开页面的“装备建模”，选择设备，展开物理参数，拖动设备/目标；计算明细展示模型、损耗、统计输出、立面路径与误差。

验证：`node --test tests/*.test.js`、`npm.cmd run build`、`node scripts/sensor_report.js`、`node scripts/deployment_report.js --example`。浏览器脚本为 `scripts/sensor_browser_smoke.js`，Windows 使用 `CHROMIUM_PATH` 指向本机 Edge。数据生成使用 `python scripts/prepare_data.py`，需安装 `requirements.txt`。
