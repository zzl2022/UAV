# 子任务二：多元感知装备能力特性建模

本实现基于仓库《创意科目二：反无装备优化部署与仿真推演》PDF 的子任务二与 `创意二文件/创意二数据集/装备参数.doc`，在郑州真实建筑与 DEM 上提供四类感知装备的参数化工程模型。模型版本：`sensors-1.0`。

## 操作

启动原有三维城市页面后，点击顶部“装备建模”。默认添加雷达、光电、无线电、声学各一台，共用同一示例观测位置和目标，便于比较不同机制；这不是自动求解的部署方案。

- 选择当前装备，展开型号参数修改距离、方向、视场、阈值及该类传播参数；输入合法数值后自动重算。
- 使用“在地图选装备点 / 在地图选目标点”，点击真实建筑或地形。装备点放在所选表面上方 2 m，目标放在表面上方 50 m；可以继续编辑坐标。
- 位置输入为局部 ENU 的东、北、上坐标，单位米。内部 Three.js 存储为 `[east, up, -north]`。上坐标不是海拔或离地高度。方向北为 0°、东为 90°，俯仰向上为正。
- “目标与工作模式”可切换可见光宽/窄视场、热成像及无线电发射/静默；目标尺寸、RCS、EIRP、声压、频率、速度、同时目标数可调。
- “环境与站网参数”可调整降雨、能见度、照度、云雾比衰减、电磁底噪/同频干扰/串扰、各类噪声、温度、风速、折射附加损耗、TDOA 站数及 GDOP。
- 可从七个设备预设添加设备，最多 64 台，也可删除到 0 台。页面针对同一个目标计算各台设备的感知状态，并显示选中设备的几何、损耗、信噪比、误差与边界原因。
- “导出参数与计算报告”输出 JSON，包括坐标原点、ECEF 变换、设备、目标、环境、参数来源、输入 GIS 哈希、结果和路径上下文。“导入参数方案”校验版本/原点/参数后，使用当前城市重新计算，忽略文件中的旧结果。无效导入不覆盖现有方案。
- 彩色球为装备，红球为目标，红/绿实线仅对应选中设备的目标路径。半透明范围体为标称距离及瞬时视场的阴影示意，包含近距盲区并随范围、方向和宽窄视场等参数更新；阴影未按建筑裁切，不能作为有效覆盖图。面板“当前网格未检出遮挡”也不等于实际环境绝对无遮挡。

## 统一几何与遮挡

感知计算复用子任务一生成的 LoD1 建筑和 DEM。通过 BVH 加速的三角网格射线求交识别建筑/地形遮挡，保留原始三角面序号以支持建筑属性索引。建筑内院保留为空，不使用包围盒直接代替实体遮挡。

同一路径还按约 15 m 间隔（最多 1024 段）向 DEM 查询，估算端点地面高度、地形突起和覆盖空缺。报告记录实际采样间距。端点或采样路径落在 DEM 空缺外时，结果为“覆盖数据不足”，不宣称完整无遮挡；这是采样检查，并不证明所有子像元区域均有地形。

建筑/影像的显示开关不会关闭物理遮挡。原始白模只作显示对比，遮挡计算始终用重建建筑和 DEM，避免双重几何。没有树木、围墙细节、桥梁细节等未提供的数据，因此对应遮挡没有被虚构加入。

通用硬边界包括近距盲区、标称距离上限、方位/俯仰视场、模型并发容量。所有输入参数及导入文件都进行范围/有限数校验，支持 0°/360° 方位接缝。

## 雷达模型

距离单位 m，路径长度 `d`，参考距离 `R`，目标/参考 RCS 为 `σ / σref`：

```text
SNR = SNRref + 40 log10(R/d) + 10 log10(σ/σref) - ΣL
margin = SNR - SNRthreshold
Lrain = 2 × d(km) × k × rain(mm/h)^α
Lcloud = 2 × d(km) × cloudSpecificAttenuation(dB/km)
```

额外损耗包括地面双径、用户给定的城市杂波、电磁底噪、同频干扰和设备串扰。雨衰采用幂律形状，但默认 k/α 仅为可调示例，不宣称是指定频率/极化的 ITU-R 标定系数。云雾衰减使用独立比衰减参数，不把光学能见度直接换算成雷达雨雾衰减。

建筑或地形阻断直达路径时不判为可感知。SNR/裕量是未考虑硬截断前的参考链路预算；必须同时看判定原因。当前路径等效距离为 `R × (σ/σref)^(1/4) × 10^((SNRref-SNRthreshold-ΣL)/40)`，再受标称上限约束；它不是整个区域的统一有效半径。

误差从文档参考距离/角误差起算，按 `10^(max(0,-margin)/20)` 放大并限制放大量。此关系是未标定的趋势模型，不能宣称为真实 CRLB 或厂商精度曲线。

地面双径还生成一个虚拟回波候选：`apparentRange = (directPath + reflectedPath)/2`，并估算距离偏差、相对功率及相对于参考距离误差的可分辨性。虚警风险指标由双径与杂波/干扰构造，范围 0–1；它不是实测虚警概率，也不代表已经生成了可信虚假目标位置。

## 光电模型

可见光宽/窄视场与热成像分别使用可调水平视场和文档图像尺寸。垂直视场按图像宽高比推导，按当前云台指向做瞬时视场约束：

```text
pixels = imageWidth × targetSize / (2 × d × tan(horizontalFov/2))
β = 3.912 / visibility(km)
transmission = exp(-β × d(km)) × 10^(-rainLoss/20)
visibleLightFactor = min(1, illuminance/minLux)
thermalFactor = targetThermalContrast
有效像素 = pixels × transmission × 对应通道系数
margin = 20 log10(有效像素 / requiredPixels)
```

识别需满足无遮挡、在当前瞬时视场内、有效像素达到阈值，并且可见光达到最低照度。热成像不使用可见光照度门限，但仍受能见度近似损耗、热对比与像素限制；没有完整红外波段辐射传输模型。

以有效像素/对比度表示识别能力边界，不输出虚构的分类准确率。精确识别概率需要标注图像、算法 ROC/混淆矩阵和通道标定数据。

## 无线电模型

```text
SNR = SNRref + 10n log10(R/d) + EIRPtarget - EIRPref - ΣL
ΣL = 穿透损耗 + 单刀刃绕射近似 + 地面双径 + 底噪 + 同频干扰 + 串扰
穿透损耗 = 遮挡建筑个数 × 可调每栋损耗
```

信号必须处于接收频段并且目标正在发射；静默或频段不匹配时感知失效，SNR/裕量显示为空，等效距离为 0。X1C 按文档离散频点及可调半带宽判定，不能把 0.9–5.8 GHz 整段都视为可接收。

角误差、多径角偏差和多径多普勒展宽提供趋势指标。参考网络定位误差按 GDOP、SNR 退化与多径指标放大。少于 4 个参与站时不输出三维 TDOA 网络误差，但不禁止单站频谱感知。当前没有实际站网坐标、时钟同步和时差观测，不能把这个误差估计称为完整 TDOA 定位求解。

城市参考半径本身已包含不明确的环境条件，叠加损耗后可能存在重复计入；需要校准参考半径与环境损耗，不能将输出当作设备实测覆盖。

## 声学模型

```text
合成背景噪声 = 10 log10(Σ 10^(各声源dB/10))
接收声压 = targetSPLat1m - 20 log10(d)
           - 空气吸收 - 穿透 - 绕射 - 双径 - 折射附加损耗
SNR = 接收声压 - 合成背景噪声
声速 = 331.3 + 0.606 × 温度(°C) + 沿路径风速(m/s)
传播时延 = d / 声速
时延位置滞后 = 目标速度 × (更新周期 + 传播时延)
```

独立叠加参考背景、交通、施工、人群、风噪、雨噪。风速/降雨强度不会自动决定噪声声压，需给定声级；避免凭空生成未经标定的气象噪声映射。各噪声输入需代表互不重复的声源分量，以免重复计数。

使用 20 Hz–20 kHz 内的用户指定代表声频，按地形/建筑净空与路径位置估算单刀刃绕射；不是宽带声谱积分。建筑反射/直达混叠用地面双径和偏差风险指标近似，折射使用可调附加损耗及声速项，不宣称完整求解楼群声场、温度梯度射线或真实轨迹滤波。缺乏实测声谱，无法确定对应无人机的真实探测距离。

输入声压低于/高于 28–132 dB 范围会判定越界；相对于背景的声压差超过动态范围时提示增益/动态范围校核。具体阵列配置和自动增益策略未提供，不把提示当作实测饱和结论。

## 共用传播近似与输出语义

地面双径使用端点相对 DEM 的高度：

```text
direct = sqrt(horizontal² + (ht-hr)²)
reflected = sqrt(horizontal² + (ht+hr)²)
powerFactor = |1 - ρ × direct/reflected × exp(-j phase)|²
LtwoRay = -10 log10(powerFactor)，限制在 ±30 dB
phase = 2π × (reflected-direct) × f/c
```

雷达使用往返相位的简化版本。反射系数可调，尚未按材质、极化、入射角求解。没有端点地面高度时跳过双径并提示。双径不保证单调衰减，可能发生增强或相消。

单刀刃损耗使用归一化净空与菲涅耳参数的近似形式。只有遮挡路径才施加；按报告中净空最大的代表障碍计算一次，并另加建筑穿透项。该叠加是工程代理模型，不是最优传播路径选择或多障碍严格求解。材质、墙厚与三维反射/绕射路径尚未标定。

结果分为 `within-model`（满足模型条件）、`outside-model`（存在边界/链路失效）和 `uncertain`（满足数值条件但地形覆盖不足）。`eligible` 只表示数值门限，无论其值如何都要看 `status`。输出评分是裕量映射，不是探测概率、识别准确率或覆盖率。没有实测数据时不得把模型内判定当作真实装备保证。

## 可重复验证

```bash
npm ci
npm run prepare:data
npm test
npm run build
npm run report:sensors
```

`npm test` 覆盖参考距离/阈值、距离四次方与 RCS、视场接缝、盲区、建筑/内院/地形遮挡、气象/干扰、光电昼夜/宽窄视场、静默和离散频段、TDOA 站数、声噪能量叠加、绕射、传播时延以及输入校验和参数 JSON 往返。

`npm run report:sensors` 使用真实城市场景计算默认四类设备在基线、降雨、浓雾、夜间、无线电静默、高噪街道、电磁干扰七种条件下的结果，共 28 条，输出 `artifacts/sensor-model-report.json`。报告记录输入方案、GIS/装备文档哈希、路径上下文与全部预算，可独立复查，不需要浏览器。

启动开发服务后可运行 `npm run test:sensors:browser`，验证实际界面的四类模型、参数调整、静默、站数、JSON 导入导出、非法输入、添加删除、地图点选和移动布局，并保存截图到 `artifacts/`。使用本地 Chromium，浏览器路径可通过 `CHROMIUM_PATH` 配置。原有 `npm run test:browser` 保留城市/影像/GLB 流程回归。

## 地图交互更新

- **河南博物院标注**：从建筑 `NAME` 精确匹配“河南博物院”的四栋建筑生成标注，以其中最高主楼的轮廓中心和屋顶高度定位，不使用附近“家属院”的名称匹配。城市/装备视图均有“定位河南博物院”按钮，原始数据未被修改。
- **范围阴影**：每台设备显示同色半透明三维范围体，选中设备更明显；根据最大斜距、近距盲区、方位、俯仰、水平/垂直视场实时重建。它表示标称几何范围，不代表经遮挡或气象修正后的实际有效覆盖。环境损耗通过鼠标查询和预算报告体现。
- **直接拖动**：在装备视图中，左键按住彩色装备球或红色目标球，拖到新的地面/建筑表面。保留拖动开始时相对下方表面的高度；新位置没有模型表面时保留最后有效位置。拖点时暂停地图旋转，松手/取消后恢复。拖动空白处仍是旋转地图；触摸可用同一套 Pointer Events 拖动。
- **鼠标信号查询**：将鼠标移到有模型的地面/建筑表面，右下角显示当前选中设备在该位置的估算结果。查询位置为所指表面上方高度，默认 **50 m**，可调 **0–2000 m**；白色小球表示实际查询点。查询沿用当前目标的 RCS、尺寸、发射状态、频率、声压及环境等属性，不修改固定红色目标位置。雷达/无线电展示估计信噪比 dB，声学展示 dB SPL 和信噪比，光电展示有效像素；这些单位不可当作统一 dBm 信号功率。没有接收功率标定，不虚构雷达/无线电绝对 dBm。
- **一键还原**：点击“一键还原 · 清空所有设备”立即删除所有设备、对应范围体和预算结果，保留城市与目标；不会自动补回四台设备。空方案可导出/导入，也可重新添加设备。“载入四类示例设备”是另一个明确按钮。

鼠标离开地图或无表面/无设备时不保留旧的信号数值。鼠标查询做短暂节流，以控制真实建筑/地形求交成本，读数为当前位置的近似模型值，不是现场测量。

设备超过 12 台时，仅显示当前选中设备的范围阴影，保留全部设备点位，避免大型方案的范围叠加遮住地图。
