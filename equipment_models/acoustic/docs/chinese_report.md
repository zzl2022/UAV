# 中文报告功能与验证记录

新增独立结果展示层 `src/acoustic_model/report.py`；只读取结果并生成 HTML，未修改模型计算公式和配置。
`examples/run_acoustic_demo.py` 计算完成后自动生成同名 `_report.html`。
`examples/report_acoustic_results.py` 可单独读取已有演示 JSON 生成报告，仅需 Python 标准库。

页面提供：场景横向对比、输入条件、按结果生成的中文解释、视场或声学误差尺度、
参数来源状态、原始数据及运行审计。未知字段保留原名，避免错误翻译。
报告为静态快照，修改配置后须重新计算；不重新估计能力、不新增概率、不将缺失值转为零。
场景对比不是受控实验，不自动给出最优部署或实际检测结论。

验证环境：Python 3.12.14，独立依赖目录 work/report_runtime。
完整工作副本测试结果：36 passed，包含全部原有测试及7项新增报告测试。
测试 XML：outputs/report_tests.xml（其中路径指向验证工作副本）。
原有测试未删除、未降低断言。演示重新运行后所有 scenarios 与桌面原结果完全相同。
验证覆盖：不修改输入、全部场景呈现、缺失标记、HTML字符转义、非法数据、UTF-8输出、
未知建筑路径和两种传播机制的不同解释。

桌面原 JSON 保留；已基于该文件生成中文报告。测试通过只证明软件逻辑，不能证明真实设备精度。
运行命令见 README 的“中文结果说明和场景对比”。
