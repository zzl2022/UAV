# 光电模型方法与来源边界

## 数据与来源

实现范围为任务二 NVT-951 光电能力。装备原文在 `data_inventory.md` 逐项记录。`provided` 只表示主办方参考资料提供，不等于本工程测得或厂商性能经独立验证。源码不包含雷达、无线电、声学模型或部署优化。

设备参数每项使用 `{value, unit, status, source}`；状态为 `provided`、`assumed`、`missing`、`calibrated`。缺失必须 `value: null`。计算结果增加 `derived`、`uncalibrated`、`not_applicable`。派生视场保留参与参数完整来源；环境系数全部独立存放在 `config/environment.yaml`。输出同时快照设备及环境配置，可追溯修改。用户自填参数应注明实际来源，标定值使用 calibrated。

默认设备配置仅包含原文提供的参数；实际 FOV、实际识别距离和最低照度均没有依据。`demo_overrides` 中宽高/像素判据明确为合成假设，只有显式 `--assumed-optics` 才启用。35 cm 识别描述没有距离与条件，不能推导有效识别距离；50 m/15 m/s 跟踪描述也不能当作最大范围。示例选 35 cm 目标只是输入场景假设。

## 接口及坐标约定

`load_device`、`load_environment` → `OpticalEquipment(device, environment, scene)` → `evaluate(Pose, Target, Conditions, focal_mm=...)`，返回可严格 JSON 序列化的字典。两通道共享机械姿态，各自有光学参数与环境响应。修改配置后重新加载并新建模型；模型内部深拷贝配置，避免外部修改影响已建立实例。支持多个实例、替换场景和 repeated evaluate，无全局设备状态。

`examples/run_optical_case.py` 将单个 JSON 场景转成上述对象，不引入新的计算公式。场景文件 `examples/optical_case.example.json` 的顶层字段是 `pose`、`target`、`conditions`、`focal_mm`、`scene`；输出顶层保留输入和 YAML 的绝对路径、是否启用假设光学参数、场景审计和 `result`。`scene.kind=none` 表示没有环境适配器，LOS 未知；`synthetic_empty` 表示明确的空合成建筑集合；`shapefile` 仅读轮廓且在未声明高度语义时对相交射线返回未知。三种模式的结论不得互换。场景坐标及垂直基准由调用者负责核实，脚本不会凭 `frame` 字符串证明其正确性。

`EnvironmentAdapter` 协议要求 `frame` 及 `trace_los(sensor_xyz, target_xyz)`；LOS 返回 `state: clear|blocked|unknown` 以及来源。任务一可提供真实地形、白模或其他实体的射线查询，沿用该协议。本模块自身只建立建筑简化棱柱，未实现整个三维引擎。实体树在场景创建时建立；增删建筑后新建场景。

所有 xyz 是同一米制区域平面坐标与同一垂直基准，x 东、y 北、z 向上。`local_m` 专供显式合成局部场景；实际数据使用投影 CRS 字符串。传感器、目标和场景 frame 必须一致；frame 相同仍要求调用方确认同一垂直基准。经纬度不能直接当米制输入，`transform_xy` 只变换水平坐标，不伪造垂直转换。坐标数值、姿态、尺寸、系数都验证有限性与合法范围。

yaw 以当前投影格网北为0，顺时针到东90；pitch 向上为正；roll 绕视轴旋转相机基向量。初版假设安装基座对齐格网北和水平，云台角就是此安装基座下的 yaw/pitch。安装基座不对齐时由任务一适配器换算。真实地理北与格网北的收敛角、云台零位误差需额外校准。云台范围仅用于姿态有效性，不参与光学视场角计算；没有做云台速率、加速度、自动跟踪动力学。

## 视场与像素尺度

针孔相机公式（物理尺寸与焦距同为 mm）：

`HFOV = 2 atan(sensor_width / (2 f))`，`VFOV = 2 atan(sensor_height / (2 f))`。

焦距默认取原始范围的下界（热成像固定75 mm）。可见光增大焦距会减小视场并增大目标投影。只有物理宽高完整时用此公式。否则使用直接配置 `[HFOV,VFOV]`；直接配置表示固定视场，不随焦距自动变化，修改直接 FOV 即改变视场。两者都缺失返回 missing/null。若两者都有值，物理尺寸计算优先。HFOV/VFOV 限制为 (0,180) 度。没有考虑畸变、变焦裁切、对焦呼吸及实际有效像元区域。

令世界空间目标相对位置向量为 Δ，姿态产生相机 right/up/forward 三个正交基。相机坐标为 `(x_c,y_c,z_c)`。目标中心在当前矩形视场内的条件为：

`z_c > 0`，`|atan2(x_c,z_c)| <= HFOV/2`，`|atan2(y_c,z_c)| <= VFOV/2`。

边界含在视场内，浮点角容差1e−10度。这是目标中心点判断，不能保证目标整体进入视场；部分目标出框不另行建模。与机械是否能够转到该姿态分开输出。

当目标宽高完整且在前方，示例投影为 `P_x = N_x W / (2 z_c tan(HFOV/2))`，垂直同理。目标假设正对镜头、关键尺寸沿图像轴，因此此项显式标为 assumed，不能作为任意姿态 UAV 实际像素数。`sampling_criterion_met` 只比较两轴像素数最小值与可配置阈值；满足此条件不证明能识别。没有默认 Johnson 判据或默认为真实概率的阈值。

## 建筑遮挡

GeoPandas读取完整 Shapefile，检查 CRS、字段、几何非空有效、Polygon/MultiPolygon。无效数据直接报错，需要上游显式修复；不静默丢弃或修补。官方原始 Web Mercator 虽用米单位，在当地地面距离与投影距离不一致，加载时自动估计本区域 UTM，并检查目标投影的区域适用范围及米单位；拒绝直接以3857作为计算场景。区域跨度超过6°拒绝，以防本区域模型误用到大陆尺度。

三维建筑由有效二维轮廓加 `[base_z,top_z]` 构成。`high` 字段语义未核实时 `base/top=null`；射线水平投影碰到该轮廓返回 unknown，不能得出无遮挡。没有碰到任何轮廓可以返回 clear，但范围仍仅限已加载建筑。

`HeightMapping` 必须显式声明相对高度米、基底、来源状态及垂直基准。示例可用 `high` 作相对米高度、base=0，但输出标为 assumed，并不是正式官方高度模型。若后续证实为绝对屋顶高程，应先在任务一环境模块统一垂直基准，再提供 base/top；不能直接沿用 relative-height mapping。

STRtree筛选二维相交建筑，精确求线段与 footprint 的交集。对每个连续交集分别计算射线参数区间 `[t0,t1]` 与线性 z 区间，和建筑闭合垂直区间相交则遮挡。支持孔洞、多部件、穿过、擦边、屋顶接触、垂直射线。边界包括射线端点，传感器在屋顶表面会算接触遮挡；需输入实际安装支架高于屋顶的高度。几何 z 容差1e−9 m。已确认遮挡优先于其他 unknown 候选。只有 unknown 候选则 unknown；空合成场景显式无遮挡；未加载环境返回 unknown。

局限：平顶不透明棱柱，未建屋檐、玻璃透射、内部空间、建筑材料、植被、地形遮挡、衍射或折射。DEM仅作数据审计，不在本版本自动采样为地面：其垂直基准与 high 含义未核实。白模只读取 metadata，不把包围盒/哨兵属性当楼高。

## 环境相对模型

条件含 period(日间/夜间/晨昏)、实际照度lux、可见度m、雨强mm/h、两通道独立归一化对比度、气温。period 仅是场景标签；不会凭“夜间”猜照度。改变光照需改变 lux；夜间示例使用1 lux，日间1000 lux，都是合成输入。未输入照度时可见光因子 unknown，热成像仍不使用该照度。

对距离 d(m)，采用公开写明的简单经验形式：

- 雾因子 `T_f = exp(−k_f d / V)`。V 为输入可见度，null明确表示关闭雾项（不是声称实测无雾）。可见光 k_f=3.912、热成像1.5均仅示例，热红外不能直接用此式声称真实物理传播。
- 雨因子 `T_r = exp(−k_r R d / 1000)`，R(mm/h)，k_r(h/mm/km)。示例可见光0.02、热成像0.01，不经设备实测标定。
- 可见光照度因子 `L = sqrt(min(1,lux / illumination_reference))`，参考值100 lux是归一化示例，不是最低照度。若用户提供实际 minimum_illuminance且低于阈值，L=0；原文缺失时 `below_minimum_illuminance=null`。
- 热成像不采用可见光 lux 因子，不应用可见光最低照度阈值。输入 thermal_contrast 是归一化热对比度占位接口，不由可见光反推；温差、NETD、波段、湿度响应尚待标定。
- 相对清晰度 `Q = L T_f T_r`（热成像没有L）；相对表观对比度 `C' = C T_f T_r`。两者都为未标定相对指标；缺项则null。它们反映简化趋势，不能当作图像PSNR、MTF或实验测量。
- 相对识别指标 `I = L C T_f T_r S`，若像素及判据齐全则 `S = min(1,min(P_x,P_y)/threshold)`，否则S项不使用。未使用S时输出仍可代表环境相对品质，不补造判据。blocked/视场外/机械不合法/明确温度越界时I=0；视场或LOS未知、必需环境因子缺失时I=null。缺失温度只返回工作范围未知，不额外猜测热影响。

各因子不会被当成独立识别概率；I 明确 `probability:false`、`status:uncalibrated`。真实识别概率始终null。有效识别距离默认null；若用户填写 effective_range，只输出带来源的参考值，不自动宣称雨雾环境下有效距离。可见光与热成像不做未经依据的概率融合。

## 测试与标定次序

测试使用合成棱柱、已知几何及参数，并覆盖配置合法性、变焦单调性、视场内外、旋转、孔洞与垂直射线、遮挡移除、未知高度、日夜及雨雾、双通道差异、异常坐标、非法几何、缺失指标、投影重算及环境适配器。通过测试仅证明实现符合写明的模型假设，不证明设备真实精度。

优先补充：确认 high 的单位/语义和全场垂直基准；实测或获得两通道有效尺寸/直接FOV；获得最低照度、目标姿态与像素判据；采集距离×天气×目标尺寸的带标签识别数据；用任务一真实三维射线适配器验证环境遮挡，再标定各通道质量及识别曲线。
